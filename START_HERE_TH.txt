เฟิร์มแวร์ปัจจุบัน
ESP32UnityGloveUSB/ESP32IndexContactTest/ESP32IndexContactTest.ino
Arduino IDE เลือก ESP32 Dev Module ใช้ Upload Speed 115200
การเปิด Unity อย่างเดียวไม่จำเป็นต้องอัปโหลดเฟิร์มแวร์ใหม่ ถ้าบอร์ดมีรุ่นนี้อยู่แล้ว
เปลี่ยน Serial Port ตามเครื่อง และปิด Serial Monitor ก่อนเชื่อม Unity

สายปัจจุบัน (ให้ยึดรายการนี้หากเอกสารเก่าต่างกัน)
Potentiometer: โป้ง GPIO36/VP, ชี้ GPIO39/VN, กลาง GPIO34, นาง GPIO35, ก้อย GPIO32
ขานอก potentiometer ต่อ 3V3 และ GND ส่วนขากลางต่อ GPIO ตามนิ้ว
เซอร์โวนิ้วชี้ สัญญาณ GPIO17, สายแดง Uno 5V, สายน้ำตาล Uno GND
Uno GND ต้องเชื่อม ESP32 GND ด้วย ขณะนี้ Uno ใช้จ่ายไฟเท่านั้น
กำลังจ่ายภายใต้โหลดจริงยังไม่ได้วัด

สถานะและค่าที่วัดได้
ใช้งานควบคุมเฉพาะนิ้วชี้ ตำแหน่งปล่อย 2050 us
จุดบอล 26.6% เคยทดสอบ prepare 1325 us และ contact 1316 us
สัมผัสจริงประมาณ 27.1% ผู้ใช้รายงานว่าค้างจนคลายนิ้วแล้วปล่อยได้
ค่าระหว่างจุดเป็นค่าประมาณ ยังไม่ได้ทดสอบจริงทุกตำแหน่ง
ไม่มีเซนเซอร์วัดแรง ข้อความ ACK ยืนยันรับคำสั่ง ไม่ใช่ตำแหน่งจริง

งานต่อ
ตรวจการเตรียมแขนอย่างต่อเนื่อง ค้างเมื่อสัมผัส และปล่อยเมื่อคลายนิ้ว
ตรวจการย้าย/ปรับขนาดบอลขณะเปิดควบคุม โดยไม่ปิดโหมดเอง
เคยมีปัญหาแขนขวางก่อนนิ้วเสมือนสัมผัสและสลับล็อก/ปล่อย
โปรดอ่านโค้ดปัจจุบันและทดสอบก่อนสรุปว่าปัญหาหายแล้ว

ค่าที่ไม่ติดไปกับ ZIP
OPEN/CLOSED, ตารางเซอร์โว และความเร็วที่กด Save เก็บใน PlayerPrefs ของเครื่องต้นทาง
เครื่องเพื่อนต้องตั้ง OPEN/CLOSED ให้ตรงถุงมือ และตรวจค่าตาราง/ความเร็ว
Calibration/index-observations.json เป็นประวัติการทดลอง ไม่ใช่ค่าที่ runtime โหลด
บางสถานะในประวัติและ README เป็นข้อความจากการทดลองรุ่นก่อน ให้ดูโค้ดปัจจุบันประกอบ

ไฟล์หลัก Assets/Glove
GloveReceiver.cs: USB, calibration, ส่งคำสั่ง, GUI
GloveHand.cs: แสดงการงอนิ้ว
IndexContactSimulation.cs: สัมผัสบอลและจำกัดมือเสมือน
IndexSphereDrive.cs และ FingerServoTargetPlanner.cs: คำนวณเป้าหมายเซอร์โว
ESP32IndexContactTest.ino: อ่าน potentiometer, ขับเซอร์โว, timeout ปล่อย
